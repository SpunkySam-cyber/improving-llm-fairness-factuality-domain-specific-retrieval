# Examples

`sample_transcript.txt` is a short, **synthetic** text written for this
repository (not taken from any lecture). It contains a few deliberately
mis-transcribed Islamic terms so the correction flow can be tried without
downloading any audio.

`call1_output_example.txt` shows the format Call 1 returns
(`INCORRECT: ... | POSITION: ... | CORRECT: ... | REASON: ...`, or `NO ERRORS`; positions are one-based word indexes).

No audio, real transcripts, or API responses are included in this repository.
